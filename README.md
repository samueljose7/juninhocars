# Juninho’S Car — Estética Automotiva

Site estático completo em HTML, CSS e JavaScript. Não precisa instalar dependências nem executar build.

## Subir no GitHub

1. Extraia o ZIP.
2. Crie um repositório no GitHub.
3. Envie o conteúdo desta pasta para a raiz do repositório: index.html, src, assets e demais arquivos.
4. Confirme o envio (commit).

## Publicar

Na Vercel, importe o repositório, use o preset Other, deixe o comando de build vazio e o diretório de saída como a raiz (.).

No GitHub Pages, publique a branch main e a pasta / (root). Os caminhos dos arquivos são relativos e funcionam em subpastas.

## Editar

- index.html: textos, serviços, avaliações, contatos e mapa.
- src/styles.css: cores, layout e adaptação para celular.
- src/main.js: menu e mensagens de orçamento; telefone na constante WHATSAPP_PHONE.
- assets/: logo, imagens e favicon.

O formulário prepara a mensagem e abre o WhatsApp; não exige servidor ou banco de dados. Fontes, mapa e WhatsApp usam serviços externos. Fotos de serviços são ilustrativas.
